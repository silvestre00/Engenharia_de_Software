Repositório destinado ao armazenamento de **códigos, exercícios e projetos desenvolvidos durante a graduação em Engenharia de Software**.

O objetivo deste repositório é organizar os estudos, registrar a evolução no aprendizado e centralizar projetos acadêmicos desenvolvidos ao longo do curso.

---

# 🚀 Tecnologias Utilizadas

Atualmente os projetos utilizam principalmente:

- ☕ **Java**
- 🗂 **Git & GitHub**

Com o avanço do curso, novas tecnologias e linguagens podem ser adicionadas.

---

# 🎯 Objetivo do Repositório

- Armazenar códigos desenvolvidos durante a graduação
- Organizar exercícios e projetos por disciplina
- Registrar evolução no aprendizado em programação
- Servir como **portfólio acadêmico**

---

# 📖 Conteúdos que podem aparecer neste repositório

Durante o curso podem aparecer implementações relacionadas a:

- Lógica de programação
- Estruturas de dados
- Programação orientada a objetos
- Arquitetura de software
- Sistemas distribuídos
- Algoritmos
- Desenvolvimento backend
- Projetos acadêmicos
